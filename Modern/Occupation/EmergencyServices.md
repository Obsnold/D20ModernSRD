# Emergency Services

Rescue workers, firefighters, paramedics, hazardous material handlers,
and emergency medical technicians fall under this category.

| Stat | Value |
|---------------------------|---------|
| Prerequisite | Age 18+ |
| Reputation Bonus Increase | — |
| Wealth Bonus Increase | +2 |

## Skills

Choose two of the following skills as permanent class skills. If a skill
the character selects is already a class skill, he or she receives a +1
competence bonus on checks using that skill.

- Balance
- Climb
- Computer Use
- Drive
- Jump
- Knowledge (behavioral sciences)
- Knowledge (earth and life sciences)
- Knowledge (technology)
- Search
- Treat Injury
- Swim
