# Law Enforcement

Law enforcement personnel include uniformed police, state troopers,
federal police, federal agents, SWAT team members, and military police.

| Stat                      | Value   |
| ------------------------- | ------- |
| Prerequisite              | Age 20+ |
| Reputation Bonus Increase | —       |
| Wealth Bonus Increase     | +1      |

## Skills

Choose two of the following skills as permanent class skills. If a skill
the character selects is already a class skill, he or she receives a +1
competence bonus on checks using that skill.

- Diplomacy
- Drive
- Gather Information
- Intimidate
- Knowledge (civics)
- Knowledge (earth and life sciences)
- Knowledge (streetwise)
- Knowledge (tactics)
- Listen

## Bonus Feat

Select one of the following:

- Combat Martial Arts
- Armor Proficiency (light)
- Personal Firearms Proficiency
