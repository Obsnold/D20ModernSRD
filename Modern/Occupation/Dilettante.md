# Dilettante

Dilettantes usually get their wealth from family holdings and trust
funds. The typical dilettante has no job, few responsibilities, and at
least one driving passion that occupies his or her day. That passion
might be a charity or philanthropic foundation, an ideal or cause worth
fighting for, or a lust for living a fun and carefree existence.

| Stat                      | Value   |
| ------------------------- | ------- |
| Prerequisite              | Age 18+ |
| Reputation Bonus Increase | +1      |
| Wealth Bonus Increase     | +6      |

## Skills

Choose one of the following skills as permanent class skills. If a skill
the character selects is already a class skill, he or she receives a +1
competence bonus on checks using that skill.

- Gamble
- Intimidate
- Knowledge (current events)
- Knowledge (popular culture)
- Ride

Or add a new Speak Language.
