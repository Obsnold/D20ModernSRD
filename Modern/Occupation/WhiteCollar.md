# White Collar

Office workers and desk jockeys, lawyers, accountants, insurance agents,
bank personnel, financial advisors, tax preparers, clerks, sales
personnel, real estate agents, and a variety of mid-level managers fall
within the scope of this starting occupation.

| Stat                      | Value   |
| ------------------------- | ------- |
| Prerequisite              | Age 23+ |
| Reputation Bonus Increase | —       |
| Wealth Bonus Increase     | +3      |

## Skills

Choose two of the following skills as permanent class skills. If a skill
the character selects is already a class skill, he or she receives a +1
competence bonus on checks using that skill.

- Computer Use
- Diplomacy
- Knowledge (art)
- Knowledge (business)
- Knowledge (civics)
- Knowledge (earth and life sciences)
- Knowledge (history)
- Knowledge (physical sciences)
- Knowledge (technology)
- Research
