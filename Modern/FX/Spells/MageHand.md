# Mage Hand

| Stat | Value |
|---|---|
| School | Transmutation |
| Level | Mage 0 |
| Components | V, S |
| Casting Time | Attack action |
| Range | Close (25 ft. + 5 ft./2 levels) |
| Target | Nonmagical, unattended object weighing up to 5 lb. |
| Duration | Concentration |
| Saving Throw | None |
| Spell Resistance | No |

The caster can lift an object and move it at will from a distance. As a
move action, the caster can move the object up to 15 feet in any
direction, though the spell ends if the distance between the caster and
the object ever exceeds the spell’s range.
