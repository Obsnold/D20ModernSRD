# Flaming Wrath

| Stat | Value |
|------------------|---------------------------------------|
| School | Evocation |
| Descriptors | Fire |
| Level | Acolyte 5 |
| Components | V, S, DF |
| Casting Time | Attack action |
| Range | Medium (100 ft. + 10 ft./level) |
| Area | Cylinder (10-ft. radius, 40 ft. high) |
| Duration | Instantaneous |
| Saving Throw | Reflex half |
| Spell Resistance | Yes |

This spell produces a vertical column of divine fire roaring downward.
The spell deals 1d6 points of fire damage per caster level (maximum
10d6).
