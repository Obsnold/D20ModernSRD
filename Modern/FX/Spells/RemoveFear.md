# Remove Fear

| Stat | Value |
|---|---|
| School | Abjuration |
| Level | Acolyte 1 |
| Components | V, S |
| Casting Time | Attack action |
| Range | Close (25 ft. + 5 ft./2 levels) |
| Targets | One creature plus one additional creature/four levels, no two of which can be more than 30 ft. apart |
| Duration | 10 minutes (see text) |
| Saving Throw | Will negates (harmless) |
| Spell Resistance | Yes (harmless) |

The caster grants the target a +4 morale bonus against fear effects for
10 minutes. If the subject is suffering from a fear effect when
receiving the spell, it gets a new save with a +4 morale bonus.

Remove fear counters and dispels cause fear.
