# Ray of Fatigue

| Stat             | Value                           |
| ---------------- | ------------------------------- |
| School           | Necromancy                      |
| Level            | Mage 1                          |
| Components       | V, S, M                         |
| Casting Time     | Attack action                   |
| Range            | Close (25 ft. + 5 ft./2 levels) |
| Effect           | Ray                             |
| Duration         | 1 minute/level                  |
| Saving Throw     | No                              |
| Spell Resistance | Yes                             |

The caster must succeed at a ranged touch attack with the ray to strike
a target. The subject is immediately fatigued for the spell’s duration.
A fatigued character suffers a –2 penalty to Strength and Dexterity and
can’t run or charge. This spell has no effect on a creature who is
already fatigued.
