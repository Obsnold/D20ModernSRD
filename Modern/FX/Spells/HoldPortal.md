# Hold Portal

| Stat | Value |
|------------------|------------------------------------|
| School | Abjuration |
| Level | Mage 1 |
| Components | V |
| Casting Time | Attack action |
| Range | Medium (100 ft. + 10 ft./level) |
| Target | One portal, up to 20 sq. ft./level |
| Duration | 1 minute/level |
| Saving Throw | None |
| Spell Resistance | No |

This spell magically bars a door, gate, window, or shutter of wood,
metal, or stone. The magic holds the portal fast, just as if it were
securely closed and normally locked. A knock spell or a successful
dispel magic spell can negate the hold portal. For a portal affected by
this spell, add 5 to the normal DC for forcing the portal.
