# Resistance

| Stat             | Value                   |
|------------------|-------------------------|
| School           | Abjuration              |
| Level            | Acolyte 0, Mage 0       |
| Components       | V, S, M/DF              |
| Casting Time     | Attack action           |
| Range            | Touch                   |
| Target           | Creature touched        |
| Duration         | 1 minute                |
| Saving Throw     | Will negates (harmless) |
| Spell Resistance | Yes (harmless)          |

The subject is granted a +1 resistance bonus on saving throws.
