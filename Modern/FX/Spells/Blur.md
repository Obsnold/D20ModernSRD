# Blur

| Stat             | Value                   |
| ---------------- | ----------------------- |
| School           | Illusion                |
| Level            | Mage 2                  |
| Components       | V                       |
| Casting Time     | Attack action           |
| Range            | Touch                   |
| Target           | Creature touched        |
| Duration         | 1 minute/level (D)      |
| Saving Throw     | Will negates (harmless) |
| Spell Resistance | Yes (harmless)          |

The subject’s outline appears blurred, shifting and wavering. This
distortion grants the subject one-half concealment (20% miss chance).

A see invisibility spell does not counteract the blur effect, but a true
seeing spell does. Opponents who cannot see the subject ignore the
spell’s effect.
