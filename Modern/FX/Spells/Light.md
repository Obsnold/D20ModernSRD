# Light

| Stat             | Value                |
|------------------|----------------------|
| School           | Evocation            |
| Descriptors      | Light                |
| Level            | Acolyte 0, Mage 0    |
| Components       | V, M/DF              |
| Casting Time     | Attack action        |
| Range            | Touch                |
| Target           | Object touched       |
| Duration         | 10 minutes/level (D) |
| Saving Throw     | None                 |
| Spell Resistance | No                   |

This spell causes an object to glow, shedding light in a 20-foot radius
from the point the caster touches. The effect is immobile, but it can be
cast on a movable object. Light taken into an area of magical darkness
does not function.
