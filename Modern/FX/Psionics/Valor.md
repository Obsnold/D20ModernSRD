# Valor

| Stat               | Value         |
|--------------------|---------------|
| Key Ability        | Strength      |
| Level              | Battle Mind 0 |
| Display            | Audible       |
| Manifestation Time | See text      |
| Range              | Personal      |
| Target             | You           |
| Power Point Cost   | 1             |

The manifester can immediately apply a +1 morale bonus on a saving
throw.

A manifester can manifest this power instantly, quickly enough to gain
the +1 morale bonus on a saving throw in the same round. Manifesting the
power is a free action.
