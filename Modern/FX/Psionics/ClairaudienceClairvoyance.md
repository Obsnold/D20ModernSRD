# Clairaudience/Clairvoyance

| Stat               | Value              |
|--------------------|--------------------|
| Key Ability        | Wisdom             |
| Level              | Telepath 2         |
| Display            | Visual, Audible    |
| Manifestation Time | Attack action      |
| Range              | See text           |
| Duration           | 1 minute/level (D) |
| Saving Throw       | None               |
| Power Resistance   | No                 |
| Power Point Cost   | 3                  |

This power enables a manifester to concentrate on some locale and hear
or see (manifester’s choice) almost as if he or she were there. Distance
is not a factor, but the locale must be known—either a place familiar to
the manifester or an obvious place.
