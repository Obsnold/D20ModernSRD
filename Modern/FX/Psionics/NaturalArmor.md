# Natural Armor

| Stat               | Value               |
|--------------------|---------------------|
| Key Ability        | Strength            |
| Level              | Battle Mind 4       |
| Display            | Olfactory, Material |
| Manifestation Time | Attack action       |
| Range              | Personal            |
| Target             | You                 |
| Duration           | 1 minute/level      |
| Power Point Cost   | 7                   |

This power provides a +4 natural armor bonus to the manifester’s
Defense. Natural armor does not carry an armor penalty and does not
reduce speed. This power’s effect does not stack with other natural
armor bonuses.
