# Far Hand

| Stat | Value |
|---|---|
| Key Ability | Constitution |
| Level | Telepath 0 |
| Display | Visual |
| Manifestation Time | Attack action |
| Range | Close (25 ft. + 5 ft./2 levels) |
| Target | An unattended object weighing up to 5 pounds |
| Duration | Concentration |
| Saving Throw | None |
| Power Resistance | No |
| Power Point Cost | 1 |

The manifester can lift and move an object at will from a distance.
After manifestation, as a move action the manifester can move the object
up to 15 feet in any direction. The power ends if the distance between
the manifester and the object ever exceeds the power’s range.
