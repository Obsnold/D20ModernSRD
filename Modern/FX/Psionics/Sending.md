# Sending

| Stat               | Value             |
|--------------------|-------------------|
| Key Ability        | Dexterity         |
| Level              | Telepath 5        |
| Display            | Mental            |
| Manifestation Time | Full-round action |
| Range              | See text          |
| Target             | One creature      |
| Duration           | 1 round           |
| Saving Throw       | None              |
| Power Resistance   | No                |
| Power Point Cost   | 9                 |

The manifester contacts a particular individual with whom he or she is
familiar and sends a short message of twenty-five words or less. The
target recognizes the manifester if it knows him or her. It can answer
in like manner immediately. The target is not obliged to act on the
message in any way.
