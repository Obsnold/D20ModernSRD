# Power Resistance

| Stat               | Value            |
| ------------------ | ---------------- |
| Key Ability        | Wisdom           |
| Level              | Telepath 5       |
| Display            | Visual, Material |
| Manifestation Time | Attack action    |
| Range              | Touch            |
| Target             | Creature touched |
| Duration           | 1 minute/level   |
| Saving Throw       | Will negates     |
| Power Resistance   | Yes              |
| Power Point Cost   | 9                |

The target is granted power resistance equal to 12 + the manifester’s
manifester level.
