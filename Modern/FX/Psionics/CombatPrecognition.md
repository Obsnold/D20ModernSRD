# Combat Precognition

| Stat | Value |
|--------------------|------------------|
| Key Ability | Wisdom |
| Level | Battle Mind 1 |
| Display | Visual, Material |
| Manifestation Time | Attack action |
| Range | Personal |
| Target | You |
| Duration | 1 hour/level (D) |
| Saving Throw | None |
| Power Resistance | No |
| Power Point Cost | 1 |

The manifester gains a +1 insight bonus to Defense. If he or she is
caught flat-footed, this bonus to Defense doesn’t apply.
