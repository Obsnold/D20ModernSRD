# Lightning Strike

| Stat | Value |
|--------------------|---------------------------------|
| Key Ability | Intelligence |
| Descriptors | Electricity |
| Level | Battle Mind 3 |
| Display | Visual |
| Manifestation Time | Attack action |
| Range | Medium (100 ft. + 10 ft./level) |
| Area | 30-ft. radius |
| Duration | Instantaneous |
| Saving Throw | Reflex half |
| Power Resistance | Yes |
| Power Point Cost | 5 |

The manifester deals 3d6 points of electricity damage to all creatures
within the area he or she designates (the manifester must be able to see
the target area or a portion of it).
