# Combat Prescience

| Stat               | Value              |
|--------------------|--------------------|
| Key Ability        | Wisdom             |
| Level              | Battle Mind 2      |
| Display            | Visual             |
| Manifestation Time | Attack action      |
| Range              | Personal           |
| Target             | You                |
| Duration           | 1 minute/level (D) |
| Saving Throw       | None               |
| Power Resistance   | No                 |
| Power Point Cost   | 3                  |

The manifester gains a +2 insight bonus on his or her attack rolls for
the duration of the power.
