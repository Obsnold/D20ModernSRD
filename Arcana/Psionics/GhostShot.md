# Ghost Shot

| Stat               | Value                           |
| ------------------ | ------------------------------- |
| Key Ability        | Dexterity                       |
| Level              | Psionic Agent 4                 |
| Display            | Visual                          |
| Manifestation Time | Attack action                   |
| Range              | Close (25 ft. + 5 ft./2 levels) |
| Target             | One firearm                     |
| Duration           | 1 minute/level                  |
| Saving Throw       | Will negates (harmless, object) |
| Power Resistance   | Yes (harmless, object)          |
| Power Point Cost   | 7                               |

This power makes bullets intangible to nonliving material, negating
cover, equipment, and shield bonuses to the target. It affects all
bullets in the magazine for the duration of the spell, or until they are
expended.
