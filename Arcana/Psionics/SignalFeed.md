# Signal Feed

| Stat               | Value                          |
|---|---|
| Key Ability        | Charisma                       |
| Descriptors        | Mind-Affecting                 |
| Level              | Telepath 5                     |
| Display            | Visual                         |
| Manifestation Time | Attack action                  |
| Range              | Close (25 ft. +5 ft./2 levels) |
| Target             | One communication device.      |
| Duration           | 1 round/level                  |
| Saving Throw       | Will negates                   |
| Power Resistance   | Yes                            |
| Power Point Cost   | 9                              |

You can create false images or sounds on an electronic device. The spell
affects those that are watching or listening the device at the time of
the power’s manifestation— those who arrive later or make their saving
throw see or hear the what is really there. Recordings of the *signal
feed *will show distortion, as well as the “real” image. Other powers
may not be used through a *signal feed.*
