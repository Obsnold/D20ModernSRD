# Detect Poison

| Stat               | Value                                      |
|---|---|
| Key Ability        | Wisdom                                     |
| Level              | Psionic Agent 0                            |
| Display            | Olfactory                                  |
| Manifestation Time | Attack action                              |
| Range              | Close (25 ft. + 5 ft./2 levels)            |
| Target or Area     | One creature, one object, or a 5-foot cube |
| Duration           | Instantaneous                              |
| Saving Throw       | None                                       |
| Power Resistance   | No                                         |
| Power Point Cost   | 1                                          |

You determine whether a creature, object, or area has been poisoned or
is poisonous. You can determine the exact type of poison with a
successful Wisdom check (DC 20). A character with the Craft (chemical)
skill may additionally try an Craft (chemical) check, DC 20.

*Note: *The power can penetrate barriers, but 1 foot of stone, 1 inch of
common metal, a thin sheet of lead, or 3 feet of wood or dirt blocks it.
